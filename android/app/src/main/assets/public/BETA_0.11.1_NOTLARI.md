# FitTrack Beta 0.11.1

- Telefonun sistem geri tuşu Android `MainActivity` içinde yakalanıp FitTrack'in ekran durumuna iletilir.
- Aktif antrenmanda geri tuşu `Antrenman iptal edilsin mi?` onayını açar; kullanıcı artık yanlışlıkla ana sayfaya düşmez.
- Kök sekmede geri tuşu uygulamayı ana sayfaya yönlendirmek yerine arka plana alır.
- Ana sayfaya üye için doğrudan antrenör sohbet kartı, antrenör/yönetici için tüm üyeleri gösteren mesaj merkezi eklendi.
- Antrenör panelindeki üye kartlarına tek dokunuşla mesaj gönderme düğmesi ve okunmamış mesaj rozeti eklendi.
- Realtime ile gelen yeni mesaj her iki tarafta `Yeni mesajın var` uyarısı ve Android yerel bildirimi oluşturur; bildirime dokununca sohbet açılır.
- Antrenör panelindeki küçük başlık, açıklama, filtre, durum, metrik, not alanı ve geçmiş yazıları büyütüldü.
- Program inceleme ekranında logo ortalandı, antrenör notu ve hareket bilgileri büyütüldü.
- Ana sayfadaki marka yazımı `FitTrack` olarak düzeltildi.
- 0.11'deki sınırsız farklı antrenman atama, eşit antrenman kartları ve RLS korumalı gerçek sohbet altyapısı korunur.

Android: `versionName 0.11.1`, `versionCode 18`, minimum API 24, hedef API 36.
