# FitTrack Beta 0.11.2

- Samsung/Android 16 cihazlarda ekranın kenarından içeri kaydırılan geri hareketi ayrıca yakalanır.
- `OnBackPressedDispatcher` ve etkin `OnBackInvokedCallback` desteği kullanılır.
- Kenardan geri hareketi onboarding, profil, hareket detayı, program detayı ve diğer iç ekranlarda telefon ana ekranına atmaz.
- Aktif antrenmanda kenardan geri hareketi `Antrenman iptal edilsin mi?` onayını açar.
- 0.11.1 mesaj merkezi, yeni mesaj bildirimleri, okunabilirlik ve FitTrack logo düzeltmeleri korunur.

Android: `versionName 0.11.2`, `versionCode 19`, minimum API 24, hedef API 36.
