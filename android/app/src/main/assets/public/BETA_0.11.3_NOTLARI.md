# FitTrack Beta 0.11.3

## Yeni program oluşturucu

- Uzun ve yoğun tek ekran kaldırıldı.
- Oluşturma akışı dört adıma ayrıldı: Bilgiler, Günler, Hareketler ve Kontrol.
- Açıklama ile genel antrenör notu isteğe bağlı alana taşındı.
- Günler ayrı kartlarla, büyük yazılar ve büyük dokunma alanlarıyla yönetiliyor.
- Hareketler arama ve kas grubu filtresiyle pencere kapanmadan toplu seçilebiliyor.
- Hareket kartlarındaki `Setleri düzenle` ve `Kaldır` eylemleri açık biçimde adlandırıldı.
- Son kontrol ekranında programın gün, hareket ve set toplamı gösteriliyor.
- Yarım kalan program yalnız adı girilmiş olsa bile taslak kaydedilebiliyor.
- Android geri tuşu ve kenardan geri hareketi oluşturucuda önceki adıma dönüyor.

## Korunan özellikler

Çoklu ve sınırsız antrenman atama, gerçek üye–antrenör sohbeti, yeni mesaj bildirimleri, büyük profil/antrenör paneli yazıları ve Android öngörülü geri desteği aynen korunur.

Android: `versionName 0.11.3`, `versionCode 20`, minimum API 24, hedef API 36.
