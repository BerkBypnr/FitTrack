# FitTrack Beta 0.10.3.1 — Hata Düzeltme Sürümü

Bu sürüm 0.10.3 telefon testlerinde bulunan sekiz benzersiz sorunu giderir:

- Kayıtlı hesap internet yokken uygulamayı yeniden açabilir; yerel veriler gösterilir ve oturum bağlantı gelince yeniden doğrulanır.
- Profil adı çevrimdışı kuyruğa yazılır ve eski bulut adı yerel güncellemeyi ezmez.
- Aynı Supabase Realtime konusu ikinci kez dinleyici eklemez.
- Android 16 geri hareketi mevcut Capacitor geri çağrısına yönlendirilir; açık katmanı kapatır ve profil sihirbazında önceki adıma döner.
- Açık temada antrenman görseli üzerindeki metinler yüksek kontrastlı kalır.
- Hareket kütüphanesi satırları tam ekran GIF/görsel ve uygulama ipuçları detayını açar.
- Tarayıcı varsayılan düğme çerçeveleri kaldırıldı; profil başlığı ve geri sayım geri düğmesi hizalandı.
- Android kesin alarm izni, uygulama içi izin yönlendirmesi ve plan doğrulaması eklendi.

Android paketi: `versionName 0.10.3.1`, `versionCode 15`, minimum API 24, hedef API 36.
