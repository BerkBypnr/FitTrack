# FitTrack Beta 0.11.4 sürüm notları

- Sürüm: `0.11.4`
- Android `versionCode`: `21`
- Paket: `com.fittracklabs.mobile`

## Öne çıkanlar

- Salon yöneticisinin ana sayfası, Programlar ve İlerleme ekranları üye yönetimi odağında yeniden düzenlendi.
- Yöneticiye canlı antrenman durumu, PT ataması, program devamlılığı ve ayrıntılı üye antrenman geçmişi eklendi.
- Program Oluşturucu’ya geçici hareket seçimi, `Seçimi uygula` / `Vazgeç`, kaydetmeden çıkış uyarısı, otomatik taslak kurtarma, silme onayı ve geri alma eklendi.
- Yayınlanmış program revizyonunda mevcut atamaları yeni sürüme taşıma veya eski sürümde bırakma seçimi eklendi.
- Salon hareket kütüphanesine özel hareket ekleme/silme eklendi; FitTrack’in 36 temel hareketi özgün GIF gösterimleriyle paketlendi.
- Genel üye takip notu program atamasına özel nottan ayrıldı.
- Dört premium tema ve yerel Inter Variable font eklendi.
- Geçici bulut hatalarının yerel oturumu giriş ekranına atması engellendi.
- Yerel veri şeması ve runtime yapılandırması `14` değerinde hizalandı.

0.11.3’ün FitTrack uygulama ikonu, adaptive icon, splash, bildirim rengi, uygulama adı, paket kimliği ve imza sertifikası korunur.
